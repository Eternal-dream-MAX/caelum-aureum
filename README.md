# CAELUM AUREUM · 金色天城

单文件 3D 体素巴洛克浮空都城。双击 `CaelumAureum.html` 即可运行——
不需要构建、不需要本地服务器、没有外部素材依赖。

## 场景构成

**主岛**（半径 78 体素，倒锥形岩体 + 垂石 + 岛缘崩石）

- 台基与 8 级巨阶，两侧基座雕像
- 中殿 60×62×38，侧墙壁柱 + 高窗 + 上层圆窗
- 正立面：深红大门、6 根巨柱、柱上楣、**断山花**、檐下涡卷托架、壁龛雕像、屋顶栏杆
- 大穹顶：鼓座（20 段带壁柱与窗洞）→ 三层圆形檐口 → 24 肋阶梯穹顶（12 分肋 + 2 道金环）→ 采光亭 → 镀金尖顶
- 双钟塔：塔身/钟楼层/顶台三段收分，四角壁柱、钟窗、双层檐口、铜绿小穹顶、旗杆
- 侧翼 + 飞扶壁 + 拱券连廊 + 4 座屋顶小穹顶
- 后殿半圆室与半穹顶
- 前广场：方尖碑 ×2、喷泉 ×2、雕像 ×6、岛缘望楼 ×2、环形栏杆
- 后花园：绿篱几何图案、修剪树、水池

**副岛 ×3**

- 左：花园岛（八角亭 + 穹顶 + 树林 + 绿篱）
- 右：神庙岛
- 后下：尖塔岛
- 之间以**阶梯式飞桥**连接（可跨高差）

**天空**

- 三层程序化云海平面（Canvas 噪声纹理，缓慢滚动）
- 34 团体素云环绕主岛
- 4 道瀑布（滚动水纹 + 底部雾团）
- 飞艇 ×2、热气球 ×2、鸽群、浮空碎石

## 技术要点

| 项 | 实现 |
|---|---|
| 体素总量 | **约 44.7 万块**（构建约 200–300 ms） |
| 渲染 | 单一 `BoxGeometry` + 按调色板色分组的 `InstancedMesh`；每帧仅 30 个 draw call |
| 实例矩阵 | 直接写 `instanceMatrix.array`（列主序），绕过 `Matrix4` 对象开销 |
| 体素仓库 | 稀疏哈希索引（`Map`），支持**后写覆盖先写**与**挖空**，这是门窗洞口、拱券穿透的基础 |
| 局部捕获 | `capture(fn)` 让任意构件函数把体素写进独立缓冲，飞艇/热气球/鸽群因此能复用全部巴洛克构件库 |
| 曲线 | 全部阶梯化：穹顶按层取整半径、涡卷对数螺旋离散采样、拱券逐层求弦长 |
| 金属 | `PMREMGenerator` 从程序化渐变生成环境贴图，否则纯金属材质在无 envMap 时会发黑 |
| 昼夜 | 两套 PS 预设全参数插值（光强/色温/雾/天空三段渐变/曝光/星点） |
| 交互 | 手写球体射线拾取（不建代理网格），命中后转 dispatch 到各特效 |

调色板：象牙白 / 暖金 / 赭石 / 灰蓝 / 铜绿 / 深红，无糖果色。

## 已知取舍

- 云海采用「程序化纹理平面 + 体素云团」混合：纯体素做 1500 半径的云海会产生数十万冗余方块。
- 瀑布为半透明滚动面片，非体素——水流用体素表现会变成一根方块柱子。
- 阴影相机覆盖 ±235 单位，副岛边缘不在阴影范围内（视觉上无影响）。
- 无头软件渲染下 FPS 读数无参考意义；真实 GPU 上 30 draw call / 45 万实例属于轻载。
